# Food Blog 🍴

## 📌 Project Overview

Food Blog is a Django-based web application for sharing and displaying food-related content.

The project includes a web interface, user registration, media content, and database integration using SQLite.

## 🚀 Features

- Food blog web interface
- User registration
- Food-related content and pages
- Media and image integration
- Database integration
- Django-based backend

## 🛠️ Technologies Used

- Python
- Django
- HTML
- SQLite
